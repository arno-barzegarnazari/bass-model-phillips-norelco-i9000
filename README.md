# Bass Model for Philips Norelco i9000 Prestige Ultra

Diffusion forecast for the Philips Norelco i9000 Prestige Ultra in France.

## Folders
- `data/` - men's grooming sales in France, 2010-2023 (Statista / GIFAM)
- `img/` - figures created by the report
- `report/` - `report.Rmd` (source) and `report.pdf` (final report)
- `helper_functions.R` - Bass model functions and plot theme

## How to run
1. Open the project in RStudio.
2. Install the packages: ggplot2, ggpubr, knitr, diffusion, scales, rmarkdown.
3. Open `report/report.Rmd` and click Knit.
